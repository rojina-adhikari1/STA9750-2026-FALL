Introduction

Netflix publishes its What We Watched (WWW) report every six months, beginning from first half of 2023 to the first half of 2026. This report analyzes Netflix’s What We Watched data to explore patterns in viewership data, identify the type of content, understand which content captures the most attention and who are the audiences in order to make informed decision making.

The goal is not just to analyze and provide practical recommendations for Netflix’s 2027 content budget but also to help Netflix unlock broader patterns to make more informed decisions about their future investment decisions.

Data Acquisition

To begin the analysis, data were loaded from seven WWW reports published on Netflix’s official website through the code provided by the instructor where these seven reports were downloaded and saved in a folder data/mp01 preventing from downloading repeatedly to save processing time.

load_netflix_data <- function(){

  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)
  
  data_dir <- path("data", "mp01")
    
  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings=FALSE, recurse=TRUE)
  }
  
  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )
  
  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    
    return(local)
  }
    
  NETFLIX_URLS |> 
    map(read_html) |> 
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |> 
    map_chr(html_attr, "href") |> 
    enframe("period", "url") |> 
   mutate(path = path(data_dir, paste0(period, ".xlsx")), 
          path = map2(url, path, download_if_needed), 
          data = map(path, read_excel, skip=3, na="*"), 
          data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`)))) |>
    unnest(data) |> 
    select(-url, -path) |> 
    mutate(year=str_sub(period, 1, 4), 
           half=str_sub(period, start=6), 
           period_start = make_date(year, if_else(half==1, 1, 7), 1), 
           period_end = make_date(year, if_else(half==1, 7, 12), if_else(half==1, 30, 31))) |> 
    filter(!is.na(`Hours Viewed`)) |> 
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"), 
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time))) |>
    select(-clean_time) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm=TRUE)), 
           .by=Title, 
           Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title = str_remove(Title, " // .*"), 
           Title = str_remove(Title, "[^[:ascii:]].*"), 
           Title = str_trim(Title)) |>
    filter(Title != "") |>
    select(year, 
           period, 
           period_start, 
           period_end, 
           Title, 
           -half, 
           Runtime, 
           Views, 
           `Hours Viewed`, 
           `Release Date`,
           `Available Globally?`, 
           live_event) |>
    rename(                 ## Task 2: Fix Column Titles
          title = Title,
          runtime = Runtime,
          views = Views,
          hours_viewed = `Hours Viewed`,
          release_date = `Release Date`,
          available_globally = `Available Globally?`
          )|>                                           # <- pipe added and task 3:Fix column types
    mutate(
      year = as.integer(year),
      available_globally = available_globally == "Yes"
    )
  }
  
  NETFLIX_DATA <- load_netflix_data()

Then, the provided code combines the seven reports into a single data frame called NETFLIX_DATA that has 61,892 rows and 11 columns which will be used for rest of this mini project.

Burstiness calculation

Code 
# period_end is off for H1 in the scaffold, so rebuild it
burstiness_data <- NETFLIX_DATA |>
  mutate(period_end_fixed = period_start + months(6) - days(1)) |>
  filter(
    !is.na(release_date),
    release_date >= period_start,
    release_date <= period_end_fixed
  ) |>
  mutate(
    days_available = as.integer(period_end_fixed - release_date) + 1,
    availability_group = case_when(
      days_available <= 14 ~ "0-14 days",
      days_available <= 30 ~ "15-30 days",
      days_available <= 90 ~ "31-90 days",
      .default = "91+ days"
    ),
    availability_group = factor(
      availability_group,
      levels = c("0-14 days", "15-30 days", "31-90 days", "91+ days")
    ),
    hours_per_day = hours_viewed / days_available
  )

burst_summary <- burstiness_data |>
  summarise(
    n_titles = n(),
    median_total_hours = median(hours_viewed),

Corporate Strategy Memo: Netflix Content Strategy for 2027 and beyond

To: Netflix leadership

From: Strategy Analyst

Date: October 2026

Subject: Improving New Releases and Live Programs

Recommendation

Netflix may rely on viewing data to make better decisions about its content. This report prioritizes two critical sections: how quickly new releases attract viewers and how many audiences watch live programs? Netflix should prioritize on promoting new titles when they are first released and carefully evaluate its live programs.

1. Prioritize new releases

The data show that titles available for 0-14 days has a median of 862,000 viewing hours per day while the titles released for 91 days and more received a median of 136,000 hours per day, meaning new titles received about 6.3 times more viewing hours per day. In simple terms, the newest title tends to get more attention shortly after release but it does not necessarily support that the title’s popularity degrade over time.

However, titles available longer tend to have higher total viewing hours which suggest that although new titles attract viewers more quickly, older titles continue to accumulate viewing hours over a longer period.

Strategic Actions: Netflix should invest heavily on promotional activities for selected titles during first two weeks of releases and see the performance before applying the same strategy for rest of the releases. However, it is important to consider the fact that release date information has missing values which may not accurately represent the true picture.

2. Carefully Evaluate Live Programming

Netflix should continue exploring different live events separately before drawing conclusion on where to invest in 2027. The data show that live-flagged titles have increased from 3 in 2024H2 to 117 in 2026H1. However, their share of total viewing hours remained within 0.31% to 0.46%. This means overall share of viewing hours remained quite small although the number of flagged titles increased.

The data also showed that Jake Paul vs. Mike Tyson show had 235,700,000 viewing hours more than the rest of the combined top-titles in the list 179,100,000)” (next 14 live-flagged titles combined). WWE programs also accounted for 88% of live flagged titles and 69% of live flagged viewing hours suggests that WWE is important part of Netflix’s content and worth evaluating for the upcoming investment plan

Strategic Actions: Netflix should not mix one-time live event with recurring programs because comparing these measures can help Netflix identify the most viewing and identify consistent audience interest before making investment decisions. Netflix should consider that viewing hours data has limitations as it cannot alone measure profitability as the dataset does not include revenue, costs or subscriber details.

Conclusion

For 2027 and beyond, Netflix should find ways to attract more viewers when new titles are released and strategically plan its promotional activities for content investments. Alongside, it should use performance data to evaluate live programs while also considering cost and revenue data (which is currently unavailable) before Netflix actually decides whether further investment is worthwhile.
